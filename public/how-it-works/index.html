How it works

A small Halloween game for one building. Residents with an orange ribbon sign up and get a funny secret name and a secret word. Hunters see the name, tower and floor, find the ribbon, and collect the word.

Privacy

When a resident signs up, the apartment number goes only to the resident and the organizer. A hunter can also add a door where they found a ribbon. That door shows its number to other families until the resident signs up, and then it switches to a secret name. The list of doors sits behind a building code, and hunters enter no names. Teams get a made-up name, and the organizer deletes all data after the night.

What gets counted

The app counts anonymous activity so the organizer can see how the night went: opens, screens viewed, teams started, doors signed up, stamps, wrong words, out of candy taps, installs and easter eggs, each with the time. A random ID saved on the phone lets it count phones without knowing whose they are.

It stores no names, no IP addresses and no apartment numbers with these counts, and it uses no advertising or third-party trackers. Rate limits use a scrambled form of the IP address that cannot be read back. Ratings are stored with the team that gave them and are never shown with its name. A team sees only its own ratings. A host sees the made-up name of every team that visited, and which of those teams they starred. A door joins a public list only after at least 3 ratings and with an average of 3 stars or more. Feedback messages are stored as written, with the time and no name. Fonts load from Google Fonts, which can see the request like any website font.

Built with

Plain HTML and JavaScript on Cloudflare Pages, with a D1 database. It installs as a home screen app and has an organizer portal for settings, lists and stats. Originally designed by Swapnil Tamse and built with Claude Code. The code is open source under the MIT license.
